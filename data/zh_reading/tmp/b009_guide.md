# batch-009 古希腊语→中文 翻译作业规范

## 数据来源
输入文件：`data/zh_reading/batches/batch-009.json`（JSON 数组，共 105 项，索引 0–104）。
每项字段：`k`（唯一键，输出原样带回）、`ctx`（出处）、`g`（古希腊语原文）、`e`（英译，仅供理解参考）。

**务必用 Python 读取该文件**，不要用 shell 直接 cat（希腊语重音符号易被破坏）：

```python
import json
d = json.load(open('data/zh_reading/batches/batch-009.json'))
print(d[0]['k'], d[0]['g'])
```

本批内容：索引 0–5 为柏拉图《斐多篇》末段（灵魂归宿神话、苏格拉底临终），
索引 6–104 为柏拉图《克里同篇》全文（苏格拉底与克里同的对话，43–53 节）。
对话体，短句往还极多。

## 翻译要求

1. **从古希腊语原文直译成中文**。英译只作理解参考，**不要**照它的句式翻，否则会有翻译腔。
   先读懂希腊语句法（分词、虚拟/祈愿语气、γάρ/οὖν/δή/ἄρα 等语气词的力度），再用通顺的汉语写出。
2. **文体**：准确、通顺、可读，用现代汉语学术书面语，但对话要有问答的力度与口语气。
   避免生硬直译（如把 γάρ 一律译成"因为"），也避免文白夹杂过度（不要用"之乎者也"式的文言腔）。
   柏拉图对话的标准中译风格可参考：`"那么"、"的确"、"正是如此"、"绝不然"、"好吧"、"让我说"`之类自然的汉语表达。
3. **术语统一**（全批一致）：
   ἀρετή 德性｜ἐπιστήμη 知识｜δόξα 意见｜ψυχή 灵魂｜δικαιοσύνη 正义｜εὐδαιμονία 幸福｜
   θεός 神｜πόλις 城邦｜φιλοσοφία 哲学｜λόγος 逻各斯/言说（视上下文）｜ἀλήθεια 真理｜
   τέχνη 技艺｜φύσις 自然/本性｜νόμος 礼法/习俗（《克里同篇》中法律拟人说话处译"法律"）｜
   δημοκρατία 民主制｜ὀλιγαρχία 寡头制｜τύραννος 僭主。
   其他常见词：ἀδικία 不义｜βλάβη 伤害｜ὁμολογία 同意/约定｜συνθήκη 契约｜
   δαίμων 神灵/守护神｜Ἅιδης 哈得斯/冥府｜Τάρταρος 塔耳塔洛斯｜Ἀχέρων 阿刻戎｜
   Ὠκεανός 俄刻阿诺斯｜Πυριφλεγέθων 皮里弗勒格同｜Στύξ 斯提克斯｜Κωκυτός 科库托斯。
4. **人名地名用通行中译**：Σωκράτης 苏格拉底｜Πλάτων 柏拉图｜Κρίτων 克里同｜
   Ὅμηρος 荷马｜Ἀθηναῖοι 雅典人｜Ἀθῆναι 雅典｜Μέλητος 美勒托｜Ἄνυτος 阿尼图斯｜
   Δελφοί 德尔菲｜Ἀπόλλων 阿波罗｜Ζεύς 宙斯｜Ἀχιλλεύς 阿基琉斯｜Ὀδυσσεύς 奥德修斯｜
   Ἑλένη 海伦｜Σοφοκλῆς 索福克勒斯｜Εὐριπίδης 欧里庇得斯｜Ἡρόδοτος 希罗多德｜
   Θουκυδίδης 修昔底德｜Ξενοφῶν 色诺芬｜Ἀριστοτέλης 亚里士多德｜Ἐπίκτητος 爱比克泰德｜
   Σιμμίας 西米亚斯｜Κέβης 克贝斯｜Φαίδων 斐多｜Ἀσκληπιός 阿斯克勒庇俄斯｜
   Θεσσαλία 帖撒罗尼迦/帖萨利｜Λακεδαίμων 拉刻代蒙（斯巴达）｜Κρήτη 克里特｜Θῆβαι 底比斯。
5. **不要**加译者注、不要加解释性括号、不要添加原文没有的内容。残句就照实译。
6. 段落中形如 `[...]` 的方括号是校勘符号，译文里去掉。行首的 `>` 是分段标记，也去掉。
7. 极短的段落（单个连接词、单个回答如 ναί / πάνυ μὲν οὖν / οὐδαμῶς / δῆλα δή）按上下文
   译成通顺的短句片段：ναί 是/对；πάνυ μὲν οὖν 正是如此/的确如此；οὐδαμῶς 绝不然/决不；
   δῆλα δή 显而易见；πῶς δʼ οὔ; 怎么会不呢？；πῶς γὰρ οὔ; 那还用说？；ἔστι ταῦτα 是这样；
   ἀληθῆ λέγεις 你说得对；οὐ δῆτα 不；οὐ φαίνεται 看来不是。**不要**让短答显得干瘪，
   但**不要**擅自扩写成长句，始终保持与原文相称的分量。
8. 长段落内部若原文含多个转折（μὲν…δέ、ἀλλά、γάρ 等），中文可分句甚至分段，
   用 `\n` 表示换段（与 `data/zh_reading/out/batch-000.json` 的已有风格一致）。
9. 《克里同篇》多处出现法律/礼法拟人化的长段（"法律们说……"），保持这种庄严的口吻。
   苏格拉底自称 ὁμολογήσας（已经同意过）这类法律论证用语，要译出论辩的严密。

## 输出

写到指定的分片文件，格式为 JSON 数组，**只含你负责的索引范围**，顺序与输入相同：

```json
[{"k": "tlg0059/tlg003#0#0", "zh": "……"}, ...]
```

- **必须包含分派给你的每一个 k**，个数、拼写完全一致，顺序相同。
- UTF-8，正常中文，**不要** `\uXXXX` 转义（用 `ensure_ascii=False` 写出）。
- 写完自己核对键数，并在回复中报告分到的索引范围与条目数。

建议写法：

```python
import json
d = json.load(open('data/zh_reading/batches/batch-009.json'))
out = []
for i in range(LO, HI+1):
    out.append({"k": d[i]['k'], "zh": ZH[i]})
json.dump(out, open('data/zh_reading/tmp/b009-X.json','w'), ensure_ascii=False, indent=1)
print(len(out))
```

翻译质量要求：这是要进入正式阅读平台的成品译文，须逐句核对希腊语，不得漏译、不得凭英译意会、
不得为求通顺而删改原文的论辩结构。
