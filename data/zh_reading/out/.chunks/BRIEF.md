# 翻译任务说明（修昔底德《伯罗奔尼撒战争史》卷一部分）

## 任务
把指定索引范围内的古希腊语原文（修昔底德，卷 1 科基拉辩论与随后海战叙事；末 4 段属卷 2）
**从古希腊语直译成高质量中文**，写入指定的 chunk JSON 文件。

## 硬性要求
1. **从希腊语原文直译**。`e` 字段是英译，仅作理解参考，**绝不可照抄句式**（且本批英译与希腊语段落整体错位一句，
   很多段落的英译其实是上一段的译文，参考价值有限，遇到矛盾一律以希腊语原文为准）。`e` 为空时更要靠原文判断句读。
2. 文体：现代汉语学术书面语，准确、通顺、可读。修昔底德的演说辞要有论辩的力度与锋刃，长句可拆成中文短句，
   保留转折（μέν…δέ、γάρ、οὖν、καίτοι 等）的逻辑推进；叙事部分清晰、凝练。
   不押韵、不用文言腔、不堆四字格。
3. **术语统一**（全批一致）：
   ἀρετή 德性｜ἐπιστήμη 知识｜δόξα 意见｜ψυχή 灵魂｜δικαιοσύνη 正义｜εὐδαιμονία 幸福｜θεός 神｜
   πόλις 城邦｜φιλοσοφία 哲学｜λόγος 逻各斯/言说（演说场合可译"话/言辞"）｜ἀλήθεια 真理｜τέχνη 技艺｜
   φύσις 自然/本性｜νόμος 礼法/习俗（本批多指"惯例、成规、约定"，按语境选词并保持一致）｜
   δημοκρατία 民主制｜ὀλιγαρχία 寡头制｜τύραννος 僭主｜στρατηγός 将军｜ναῦς 战船（ναυτικόν 海军/舰队）｜
   ὕβρις 僭越（动词 ὑβρίζω 可译"凌辱、肆意欺凌"）｜τίμη 荣誉｜ἕξις 品质｜μεσότης 中道｜φρόνησις 明智｜
   προαίρεσις 选择｜ἐγκράτεια 自制。
   其他常用对应：ξυμμαχία 同盟｜ἐπιμαχία 防守同盟｜σπονδαί 休战协定｜ἀπόικοι 殖民者/移民｜μητρόπολις 母邦｜
   δίκη 公道/裁判（δίκαιος 公正的）｜ξυμφέρον 利益/有利｜ἀνάγκη 必然/必要｜καιρός 时机｜τύχη 机运｜
   ἀρχή 霸权/统治（雅典"帝国"语境用"霸权"或"统治"）｜δύναμις 实力/兵力｜γνώμη 判断/主张｜
   εἰκός 情理之常｜σῶφρον / σωφροσύνη 节制｜ἀσφάλεια 安全｜ὄνομα 名义。
4. 人名地名用通行中译：Σωκράτης 苏格拉底｜Πλάτων 柏拉图｜Ὅμηρος 荷马｜Ἀθηναῖοι 雅典人｜
   Σπαρτιᾶται 斯巴达人｜Λακεδαιμόνιοι 拉栖代梦人（斯巴达人）｜Μέλητος 美勒托｜Δελφοί 德尔菲｜
   Ἀπόλλων 阿波罗｜Ζεύς 宙斯｜Ἀχιλλεύς 阿基琉斯｜Ὀδυσσεύς 奥德修斯｜Ἑλένη 海伦｜
   Κορίνθιοι 科林斯人｜Κερκυραῖοι 科基拉人｜Ἐπίδαμνος 埃皮达姆诺斯｜Ἀμπρακιῶται 安布拉基亚人｜
   Λευκάδιοι 琉卡斯人｜Μεγαρεῖς 麦加拉人｜Ἠλεῖοι 埃利斯人｜Ἀνακτόριοι 阿纳克托里翁人｜
   Ζακύνθιοι 扎金索斯人｜Θεσπρωτίς 忒斯普罗提斯｜Χειμέριον 喀墨里翁｜Ἐφύρη 厄菲拉｜
   Ἀχερουσία λίμνη 阿刻卢西亚湖｜Ἀχέρων 阿刻戎河｜Θύαμις 堤阿米斯河｜Κεστρίνη 刻斯特里涅｜

   拉丁化作答按通行中译音写即可（如 Ξενοκλείδης → 克塞诺克勒德斯）。
5. **不要**加译者注、不要加解释性括号、不要补充原文没有的内容。残句照实译（如 κἂν ἐλάσσων ᾖ… 就译成残句片段）。
6. 原文里形如 `[...]` 的方括号是校勘符号，译文里去掉；行首 `>` 分段标记也去掉；
   校勘符号 `〈…〉` 里补的字按文意直接融入译文，不加括号。
7. 极短段落（单个连接词、短语）按上下文译成通顺的短句片段，不要译成孤立的一个字。
8. 希腊语引号 ‘ ’ 与 ’ 在中文里按语义处理：对话直接用引号「」或不用引号皆可，但同一段落内保持一致即可；
   不要保留希腊语引号字符。
9. 汉语引号统一用中文全角引号（“ ” 或 「 」），破折号统一 ——。

## 输出格式
写 UTF-8 JSON 数组，元素顺序与输入索引顺序完全一致，每项只要两个键：
`[{"k": "<16位哈希原样>", "zh": "<中文译文>"}, ...]`
不得改写 k。不要 \uXXXX 转义。不要输出除该 JSON 数组以外的内容到文件。
